# Random Number Generator (0-255)

A collection of HTML and JavaScript programs that generate random numbers in the range 0 to 255 (8-bit values).

## Files

### `index.html`
A clean, modern random number generator with:
- Beautiful gradient UI design
- Random number generation (0-255)
- Multiple number format displays (Decimal, Hexadecimal, Binary)
- Color preview showing the number as grayscale RGB value
- Keyboard support (Space/Enter to generate)
- Responsive design

![Simple Version](https://github.com/user-attachments/assets/b7f27895-39d9-4b96-8f38-e4525f0afd0a)

### `complete.html`
A feature-rich version with additional functionality:
- All features from the simple version
- Generate multiple random numbers at once
- Sequential number display (0-255)
- History tracking with statistics
- Octal number format support
- Advanced keyboard shortcuts
- Detailed educational information about 0-255 range

![Complete Version](https://github.com/user-attachments/assets/fe619caa-cb92-499c-9f2a-e951c7420b29)

### `random-generator.js`
A standalone JavaScript class for advanced random number generation with:
- Object-oriented design
- History management
- Statistical analysis
- Multiple generation modes (even, odd, prime numbers)
- Utility functions for number conversion

## Usage

1. **Simple Version**: Open `index.html` in any web browser
2. **Complete Version**: Open `complete.html` in any web browser
3. **Standalone JS**: Include `random-generator.js` in your project

## Features

### Why 0-255?
The range 0-255 is significant in computing because:
- **8-bit values**: Range of values that can be stored in one byte
- **RGB colors**: Each color channel (Red, Green, Blue) uses values 0-255
- **ASCII codes**: Extended ASCII characters use codes 0-255
- **Binary representation**: 8 bits can represent 2^8 = 256 different values (0-255)

### Interactive Features
- Click to generate random numbers
- Keyboard shortcuts (Space/Enter for generation)
- Multiple number format displays
- Visual color representation
- History tracking and statistics
- Sequential number display mode
